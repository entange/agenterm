Know what your agents left running.

agenterm runs your dev servers, watchers, and test loops in terminals that outlive the agent that started them. Every task has an id, so it never starts twice, and you can watch it, type into it, or stop it.

Download for Mac

Free and open source. Also for Intel Macs, and Linux through npm.

Agents forget what they started. agenterm keeps the list.

  • Nothing starts twice

    Run the same id, or the same command in the same folder, and you get the task that is already running.

    agenterm run --id web

  • One list for every agent

    Claude Code, Codex, and your own terminal see the same tasks, with their status, ports, and folder.

    agenterm ls

  • Outlives the session

    Tasks keep running after the agent or terminal that started them exits. Their output stays readable.

    agenterm logs web -f

  • Stops cleanly

    Ctrl+C first, then the whole process tree. No stray node process holding your port.

    agenterm stop web

Every task, one click from its terminal.

The Mac app groups tasks by project or by who started them. Click one and type straight into it. Ports open in your browser, and a notification tells you when something fails in the background.

Connect your agent.

agenterm is an MCP server. Its tools match the CLI: run, list, logs, input, stop, and remove. Agents can also call the CLI directly. 

claude mcp add --scope user agenterm -- agenterm mcp
codex mcp add agenterm -- agenterm mcp
{ "mcpServers": { "agenterm": { "command": "agenterm", "args": ["mcp"] } } }

Apps opened from the Dock may not see your shell's PATH. If yours cannot find the command, use the full path that which agenterm prints.

Add the skill

It tells agents when to reach for agenterm: dev servers and watchers, yes; ls and git status, no. Works with Claude Code, Codex, Cursor, and other agents that read skills. 

npx skills add entange/agenterm

The whole CLI.

Refer to a task by its id, its title, or a unique prefix of its id. run and ls take --json for scripts.

agenterm run --id web "npm run dev"
Start it, or get the one already running
agenterm ls
Every task, with ports and who started it
agenterm logs web -f
Recent output, then follow it
agenterm input web "y"
Answer a prompt
agenterm run --id web --restart "npm run dev"
Replace a running task
agenterm stop web
Ctrl+C, then end the process tree
agenterm rm web
Remove a task and its output
agenterm mcp
The same tools over MCP

Install.

Mac app

The app, the agenterm command, and the MCP server in one download. On first launch it offers to put agenterm on your PATH.

Download for Apple Silicon Download for Intel

macOS 12 or later. The app is not signed with an Apple Developer ID, so macOS asks you to confirm the first launch: open it once, then go to System Settings, Privacy & Security, and click Open Anyway.

npm

For Linux, or the CLI on its own. Needs Node.js 22 or newer. The background daemon starts on first use. 

npm install -g agenterm

Prebuilt for macOS and Linux, x64 and arm64. Nothing to compile.
